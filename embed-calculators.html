Why add a ToolPinch calculator to your site?

Free, no signup

Copy the code and paste it into any page. There's no account, no API key and no cost.

Private for your visitors

Calculations run in the visitor's browser. The widgets show no ads and don't set cookies.

Works anywhere

WordPress, Squarespace, Wix, Webflow, Blogger, Notion sites or plain HTML: anywhere you can paste an iframe.

How to install

  1. Choose a calculator above and set the width you want.
  2. Click Copy embed code.
  3. In WordPress, add a Custom HTML block. In Squarespace, use a Code block. In Wix, use Embed HTML. Paste the code and publish.

The widget resizes itself on sites that allow scripts. Elsewhere it uses the fixed height in the code, which you can change.

Terms of use

Frequently asked questions

Is the embed really free?

Yes. There is no charge, account or usage limit.

Will the widget show ads on my site?

No. Embedded calculators contain no advertising and no tracking cookies.

Can I change the colors?

Not yet. The widget uses a neutral style that fits most sites. Contact us if you need a custom version.

Do the calculators stay up to date?

Yes. The widget loads from ToolPinch, so updates such as new pay rules or holiday dates appear automatically.

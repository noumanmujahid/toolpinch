How to use this calculator

Use this to count the days, full weeks and weekdays between two dates, for example for deadlines, notice periods or project spans.

Formula

Calendar days = end date − start date. Weekdays = days from Monday to Friday in that span. Weeks = calendar days ÷ 7.

Worked examples

Mar 1 to Mar 31

30 calendar days, which is 4 full weeks and 2 extra days.

Monday to the next Monday

7 calendar days and 5 weekdays.

Same date

0 days.

Frequently asked questions

Does it remove public holidays?

No. Weekday counts include public holidays because they differ by country and year.

Is the end date included?

The result is the difference between the dates, so the start date is not counted as an extra day.

Does it handle leap years?

Yes. It uses real calendar dates.

Assumptions and limitations

Weekdays assume a Monday to Friday work week. Holidays and local calendars are not applied.
